# Typescript sucks

Here are some demonstrations why I hate typescript.
Most of them show how typescript is incorrect about its types and confidently indicates the code is *type safe* when it clearly is not.
Typescripts implementation of type hinting is at best flawed.

Most of what typescript solves, it can also do for javascript files using jsDoc.
In some cases, the experience of it automatically just picking up the types can even be easier when using plain javascript files.
